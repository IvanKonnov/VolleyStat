## 📖 О проекте

**VolleyStat** — одностраничное веб-приложение для ведения статистики волейбольных матчей. Написано как единый HTML-файл без внешних зависимостей: весь код — HTML, CSS и JavaScript — внутри одного документа. Работает офлайн, устанавливается на телефон как PWA, хранит данные в `localStorage` браузера.

Проект рассчитан на игроков-любителей и полупрофессионалов, которые хотят вести личную статистику: эффективность атаки, качество приёма, подачу, блок, полезность — по сетам и по матчам.

**Live-версия:** [https://ivankonnov.github.io/VolleyStat/](https://ivankonnov.github.io/VolleyStat/)
**Исходник:** [`index.html`](index.html)

## 🎯 Что внутри

### Семантика приёма (v6)

Каждый приём — **ровно одна из четырёх категорий**:

| Категория | Обозначение | Что значит |
|:---|:---:|:---|
| Отличный | `++` | Идеальный приём |
| Позитив | `+` | Обычный хороший приём |
| Нейтральный | `○` | Не в плюс и не в ошибку |
| Ошибка | `✗` | Потеря мяча на приёме |

**Основная метрика приёма:** `Приём (+) или лучше % = (Позитив + Отличный) / Всего`.

### Правила игры (FIVB)

- **Либеро** не подаёт, не атакует выше сетки, не блокирует — нормы по атаке/подаче/блоку для него скрыты.
- **Ничья** по сетам (например 2:2) — отдельный статус, не идёт ни в победы, ни в поражения.
- **Короткий матч** (1–2 сета) — помечается `⚠ короткий матч`.
- **Неполный матч** (счёт не во всех сыгранных сетах) — помечается `⚠` и не идёт в счётчик побед.

### Live-режим: автосчёт

- **«Убил», «Эйс», «Блок: очко»** → **+1 нам**
- **«Ошибка», «В блок», «Ошибка подачи», «Ошибка приёма»** → **+1 сопернику**
- **«Подача: в игре»** → только фиксирует попытку
- Ручная **коррекция** для ошибок соперника и судейских решений
- Кнопка **«Отменить»** откатывает любое действие через снапшоты

### Полезность (PIR)

```
PIR = (очки атаки + эйсы + блоки
     + 0.5·отличные приёмы + 0.25·обычные приёмы
     − ошибки атаки − ошибки подачи − ошибки приёма − в блок)
     / число сетов со статистикой
```

Веса настраиваются в интерфейсе. Для либеро формула сокращается до приёма.

## 💾 Бэкапы

**Данные хранятся только в вашем браузере.** Если очистить историю — они пропадут.

**Правило:** после каждой игры нажимайте **`↓ JSON`** в шапке и сохраняйте файл в облако.

Восстановление: **`↑ Импорт`** → выбрать файл.

### Миграция схемы

Старые бэкапы (v1–v5) автоматически мигрируются при импорте. Ручных действий не требуется.

| Версия | Что было | Что стало |
|:---|:---|:---|
| v1–v3 | Приём: позитив и отличный — разные | Совместимо с v5 |
| v4 | Позитив **включал** отличные | При миграции отличные вычитаются из позитива |
| v5 | Не было нейтральных приёмов | Вычисляются как `Всего − Позитив − Отличный − Ошибки` |
| **v6** | — | Актуальная семантика: все 4 категории явные |

## 📊 Нормы по амплуа

Приложение оценивает метрики игрока относительно норм для его амплуа на любительском уровне.

### Доигровщик / Диагональный

| Метрика | Плохо | Ниже среднего | Средне | Хорошо | Отлично |
|:---|:---:|:---:|:---:|:---:|:---:|
| Эфф. атаки | < 5% | 5–15% | 15–28% | 28–40% | ≥ 40% |
